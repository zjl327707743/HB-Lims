- 错把指南、译文或设备/GLP范围当通用法律：按来源/条款/适用条件登记，关键判断回官方原文。

- 规范或治理规则弱化：记录变更影响；非作者审阅；用实际反例检验引用、状态与失败输出。语义充分性仍由人审，脚本不能判断全部业务含义。
