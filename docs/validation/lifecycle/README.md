# 项目验证准备包

本目录包含 2026-11-20 基于当前 URS/架构的初始项目内容。所有记录均为 **PLANNING_DRAFT_NOT_APPROVED**，不是已执行或已批准验证文件。

- [系统影响评估 SIA](SYSTEM_IMPACT_ASSESSMENT.md)：说明 GxP 影响、独立 LIMS/HBOS 及基础设施边界、组件分类初判和待决条件。
- [验证计划 VP](VALIDATION_PLAN.md)：职责、G0–G5、原 URS-2109 全部资料项、测试/复用/偏差/放行和运行安排。
- [风险与验证规划](lifecycle-plan.json)：机器可读的 LC 规则 ID、资料索引、初始风险及候选验证场景；每项风险有真实原 URS 和 DEV 引用。
- [开发执行教程](TEAM_EXECUTION.md)：2–3 人团队每个迭代如何更新资料并交付纵向结果。
- [8 类可复用模板](../../templates/validation/README.md)：规格、风险、测试、偏差、变更、工具/供应商、总结、运行/退役。

`lifecycle-plan.json` 是固定日期的初始规划快照。后续实际评估、执行和批准形成版本化记录并进入合适受控体系，不把此快照改成“系统已验证”。已有 185 条需求追踪和工程证据登记继续为原权威；风险场景数量不是完整需求覆盖率。

治理命令 `make governance` 将检查本规划的 ID、真实 URS/DEV 关联、文件引用、风险—验证映射和草案状态。它不验证 LIMS 业务正确性，不评价真实残余风险，也不能批准使用。生成的治理 CSV 可辅助阅读，仍然只是规划导出。
