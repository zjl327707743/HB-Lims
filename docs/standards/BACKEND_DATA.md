# BE-V1 后端与数据完整性规范

采用FastAPI/Pydantic、SQLAlchemy 2.0、Alembic和PostgreSQL；模块化单体，领域分区沿用 `apps/api/modules/`。本轮仅规范，业务实现及数据库集成NOT_RUN。

## BE-01 分层与命令

router负责协议解析；schema负责边界类型；service负责授权/资质/状态/版本/事务；repository负责查询；models声明持久化与约束。不得把审核规则散落在router、前端和worker。样品、标准方法、检验、质量、资源、留样、稳定性、EM、报告及接口各域通过显式服务协作，不跨域任意改表。

受控业务使用显式动作（submit、receive、assign、record-result、correct-result、review、approve、retest），禁止通用PATCH status即可放行。例：`POST /api/v1/test-executions/{id}/commands/record-result`，包含expected_version、reason、受控字段；Idempotency-Key作为头或合同字段。查询与命令统一返回request_id、对象版本与结构化错误，不泄露跨范围对象信息。

身份、审批人、可信时间和资质不能由请求体任意指定。相同主体/命令/幂等键+相同payload返回同一结果；同键不同payload返回冲突。幂等记录由PG唯一约束保护，而不是仅靠Redis锁；有效期及重试窗口在FS中确定。

## BE-02 事务与异步

一个成功业务命令在一个PG事务中写入业务版本、签名（适用时）、审计及Outbox；任何一步失败必须回滚。失败登录/越权等安全事件在独立安全日志通道记录，不能随失败业务事务消失；安全日志与质量审计用途区分。

每请求/每异步任务独立AsyncSession，不跨并发任务共享。事务只覆盖必要数据库操作，不把网络、对象上传、IdP或渲染耗时放在长事务内。用版本列/行锁/约束处理竞争，测试死锁、超时和安全重试；数据库默认隔离级别本身不解决业务竞态。

async只用于非阻塞I/O；CPU计算、PDF渲染和阻塞SDK进入worker或受控执行器。Celery默认同步worker不能直接假定会await async函数：任务使用独立同步SQLAlchemy会话/引擎（可采用psycopg同步驱动），接口层用经验证的异步驱动；不共享事件循环、连接池或用户会话。算法纯函数可共用，worker不得代签或绕过服务层改变质量状态。

## BE-03 模型与标准版本

稳定ID区分物料批次、请验、原样、分样、检验执行、结果修订、方法/标准/公式/模板/流程版本、签名、报告版本、交接、库存流水和Outbox。样品血缘必须防环并保存分装数量/单位、位置和交接；数量关系经数据库事务验证。

批准的标准/方法等不可原地改写；新版本审批后仅用于符合规则的新执行，历史保留版本/快照。已签署结果更正建立新修订、理由和重新批准关系，原结果/签名仍可读。OOS/OOT和复测保留调查与采用理由，禁止覆盖首次异常或默认选择合格值。

## BE-04 计算、时间与审计

结果使用PostgreSQL numeric和Python Decimal，定义precision/scale、单位、修约阶段、有效数字、检测限、空值/未检、科学计数法与比较规则。API默认以十进制字符串+单位传递受控数值，拒绝NaN/Infinity和未经定义的格式。公式白名单解析，不使用eval或执行用户脚本；算法/参数/标准版本进入记录，并有QA认可的金标准及边界样例。

可信时间来自受控服务器并校时，PG用带时区时间戳，接口使用UTC ISO8601并明确展示时区；日期型字段与时间戳分开。时钟漂移、跨午夜、时区变化和恢复后顺序要测，前端固定演示日期不能进入正式记录。

审计含稳定身份、时间、对象/版本、动作、前后值、原因、请求/关联ID。应用DB角色对审计不得UPDATE/DELETE；受控运维提升权限需双人审批或适用补偿控制、独立日志和复核。hash不能代替权限/保留/审阅，超级用户仍是风险边界。保留与定期审计审阅由QA批准。

## BE-05 迁移与对外合同

Alembic autogenerate只产生草案，人工审查约束/索引/数据转换并在真实PG验证。已发布迁移不可编辑；先扩展后切换再收缩，避免旧应用与新schema不兼容。downgrade不保证恢复已删除数据，需预迁移备份、演练及forward-fix方案。迁移工具账号与应用账号隔离。

OpenAPI是合同来源，生成TS类型/客户端；Zod/Pydantic/SQLAlchemy分工明确，不让不同模型悄悄产生不同字段规则。接口变更须差异审查。列表/聚合/导出/附件共用服务端范围过滤。ERP/WMS/DMS和仪器用幂等事件及回执，不直连改库；原始仪器文件、设备身份和解析版本可追踪。
