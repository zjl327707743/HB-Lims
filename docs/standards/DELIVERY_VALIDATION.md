# VAL-V1 开发交付、环境与验证门禁

独立LIMS、自研开发、第三方验证；公司QC/QA/Owner最终批准用途、风险和发布。以下是开发要求及计划，正式业务验证均NOT_RUN。法规适用由QA确认，不由框架或技术人员自动判断。

## VAL-01 开发顺序

G0：确认URS适用主体/风险/验收、V3.1视觉、身份与签名规则、依赖/存储准入。
G1：Next/AntD主题外壳与FastAPI骨架、OpenAPI合同、合成数据、PG/Alembic、身份/权限及审计基础同步实现；不得先写一批可绕过控制的质量CRUD再补审计。
G2：第一条纵向闭环：请验→取样/合法跳过→收样分配→结果→独立复核/异常处理→签名批准→报告归档/打印。对接真实测试API，验证越权/并发/重复与失败。
G3：资源、留样、稳定性、EM和仪器等按域扩展，复用公共控制；第三方提前审查FS/DS与可测试性。
G4：固定候选制品，第三方执行批准的验证协议、偏差/整改/再测；QA批准试点与生产使用。不能将前端Mock验收等同G2或G4。

## VAL-02 CI与受控发布

GitHub Actions是当前CI。PR执行原件/规范检查；有代码后逐项增加类型/Lint、单元、OpenAPI兼容、真实PG事务与迁移、后端拒绝测试、浏览器、视觉/可访问性、依赖/许可证/secret检查及SBOM。没有实现的检查写NOT_RUN，不添加echo PASS占位Job。

构建一次、按镜像digest推广同一制品到验证及生产；冻结代码SHA、锁文件、配置摘要、迁移版本、浏览器/字体、测试数据与运行环境。Next构建期变量不得把验证环境地址固化导致生产重新构建而冒称同一制品；使用经批准运行时配置或将每份构建分别纳入验证。所有生产变更必须影响评估及必要再测试，不能自动跟随main。

分支保护、非作者评审、发布权限与部署环境批准需在GitHub服务端实际配置并测试；规范文件不等于保护生效。生产密钥不进公共CI；CI证明、日志与制品按受控存储保留，Actions一天artifact仅为本次临时开发证据，不能作为正式验证唯一档案。

## VAL-03 部署

Docker Compose可用于开发/测试及经IT批准的单机部署；Nginx为首版HTTPS入口。选择受支持基础镜像，非root、最小权限、网络隔离、healthcheck、资源限制、日志和监控；生产不挂载可随意修改的源码。数据库、broker、对象存储和管理端口不公开。开发Docker Desktop不默认成为生产设施。

DEV/TEST/VALIDATION(UAT)/PROD隔离账号、数据、密钥和配置；允许经批准合并某些非生产环境用途但不得与生产混用。单机Compose有单点风险，是否需要冗余/备用及维护窗口由RPO/RTO确定。迁移由受控单任务执行；部署失败用已验证回退/forward-fix，禁止破坏性自动downgrade。

## VAL-04 第三方证据交付

研发提供URS/差异→FS/DS→风险→测试用例→执行证据→缺陷与复测→版本的链。第三方可编制/执行/见证约定活动，不能仅出一份无原始证据的报告；企业不转移最终质量责任。IQ/OQ/PQ、DQ、FAT等按URS和QA批准策略适用，不伪造全部必须/全部已完成。

证据至少含：用例ID、URS ID、风险/控制ID、环境与软件/配置版本、执行者、时间、合成身份/数据、预期/实际、日志/截图摘要及受控路径、缺陷和复测引用、复核/批准。真实验证资料保存在企业受控系统，公开仓库仅保留脱敏定义和引用。

## VAL-05 必测控制矩阵（全部状态NOT_RUN）

| 控制/证据族 | 最小拒绝及恢复场景 | 关联 |
| --- | --- | --- |
| AUTH | 跨实验室列表/搜索/详情/附件/批量/导出；停用/过期资格；绕过Next直调API | SEC-01/02；原权限URS |
| SIGN | 错密、同人双签、本人复核、旧版本签署、授权重放、签署超时后查单 | SEC-03；原复核/签名URS |
| TX | 重复请求、同键不同payload、并发库存、审计写失败、数据库回滚 | BE-01/02 |
| DATA | 标准换版、原始OOS与复测、更正、单位/Decimal修约金标准、时区/校时 | BE-03/04 |
| FILE | 上传中断、哈希不符、恶意文件、覆盖已签署文件、未授权链接、报告版本不符 | DATA-01/02 |
| JOB | 重复/漏投、worker终止、broker故障、远期计划重建、失败通知 | DATA-03 |
| RESTORE | 真正恢复PG+对象+审计，签名报告一致及Outbox不重复放行 | DATA-04 |
| UI | V3.1同场景对照、键盘/窄屏/虚拟表格、缓存换人、前端误报成功、打印取消 | FE-01至07 |
| PERF | 代表性样品/结果/附件增长下的混合负载；保持URS-103/104标准 | TECH-V1 |

此矩阵是新增控制测试计划，不取代185条原始RTM；一条URS可能对应多个场景。尚未映射、执行和复核不得将原需求改成PASS。存储产品、精确版本、签名策略、RPO/RTO及法规适用未确认均是进入正式验证/生产的门禁，不妨碍合成环境工程开发。
